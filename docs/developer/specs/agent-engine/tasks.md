# Agent Engine — Tasks

設計：[`design.md`](design.md)　需求：[`requirements.md`](requirements.md)

- 每個階段是一或多個 pull request；一個 pull request 完成一組可以單獨上線的任務，含測試與文件（R0）。
- 每個階段結束前，在專案外的測試專案實測並把結果寫進 pull request（`design.md` §15）。
- 「相依」指同一份 spec 裡必須先完成的任務。
